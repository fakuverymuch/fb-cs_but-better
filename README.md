**Расширение для браузеров на базе Chromium (Chrome, Edge, Яндекс.Браузер, Kiwi на Android и др.)**

**Установка:**
    
• Скачайте архив с расширением из этой ветки (FBCS-BB-for-Chrome).    
• Распакуйте его в пустую папку на вашем компьютере (например, C:\FBCS-Extension).    
• Важно: не удаляйте эту папку – расширение будет загружаться из неё.

• Откройте браузер Chrome (или Edge / Kiwi / ...).    

• Включите режим разработчика:

• Перейдите на страницу chrome://extensions/ (в Edge — edge://extensions/).    
• Включите тумблер «Режим разработчика» (Developer mode) в правом верхнем углу.     

• Нажмите кнопку «Загрузить распакованное расширение» и выберите папку, в которую вы распаковали файлы.

Расширение появится в списке. Нажмите на значок пазла (🧩) в правом верхнем углу браузера, найдите иконку расширения (название «FBCS-BB» или похожее в зависимости от версии) и по желанию закрепите её (значок булавки), чтобы она всегда была видна.

**Настройка:**

• Кликните по иконке расширения на панели инструментов — откроется popup-меню с настройками.    
• Измените нужные параметры (SID, Float, цвета и т.д.) и нажмите «Сохранить».    
• Настройки сразу применятся на открытой странице fb-cs.ru. Обновлять страницу не нужно.

**Использование:**

• Зайдите на сайт fb-cs.ru в раздел маркета (например, fb-cs.ru/place/).    
• На карточках предметов автоматически появятся бейджи SID, Float, ID и StatTrak согласно вашим настройкам.    
• Расширение работает в фоне, перехватывает обновления на площадке, поэтому бейджи (элементы SID / ID) обновляются в реальном времени.
