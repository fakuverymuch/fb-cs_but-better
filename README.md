**Универсальная версия FBCS-BB для Tampermonkey**       

Подходит для любого браузера, где можно установить Tampermonkey:    
Firefox, Edge, Chrome, Kiwi, Yandex и другие. Для Android рекомендуется Firefox/Firefox Nightly, Kiwi Browser, Яндекс.Браузер    

📥 Установка Tampermonkey    
Если у вас ещё нет расширения Tampermonkey, установите его из магазина вашего браузера:    

Firefox: https://addons.mozilla.org/firefox/addon/tampermonkey/    

Chrome/Edge: https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo     

Следуйте инструкциям по установке. Дайте необходимые разрешения, в т.ч. к локальным файлам если потребуется.  

📜 Добавление скрипта    
Скачайте/скопируйте актуальную версию кода FBCS-BB_For_Tampermonkey.user.js из этой ветки кликнув по нему и нажав на триточки выбрать copy (для пк можно просто скачать файл raw).    

Откройте Tampermonkey (в панели расширений браузера или настройках) и в панели управления расширения выберите «Создать новый скрипт», обычно значок [+]    

Удалите весь шаблонный код (править –> выделить всё –> сотрите) и полностью вставьте скопированное содержимое актуального кода. Или добавьте скачаный файл на ПК просто перетянув файл в окно панели управления расширения.        

Скрипт автоматически активируется на fb-cs.ru.     

⚙️ Настройка    
Аналогично Safari-версиям, используется хэш #nastroyki в конце любого URL сайта:    

Перейдите на fb-cs.ru/place/#nastroyki (или просто fb-cs.ru/#nastroyki) и т.п.      

В появившемся окне измените настройки цвета, sid, id и т.п. и нажмите «Сохранить» или Отмена чтобы выйти без применения изменений.    

Настройки сохраняются в локальном хранилище даже после перезагрузки страницы и обновления браузера. Настройки применяются автоматически, достаточно пролистнуть страницу инвентаря/торговой площадки или обновить страницу сайта.
