Универсальная версия FBCS-BB для Tampermonkey    

Подходит для любого браузера, где можно установить Tampermonkey:    
Firefox, Edge, Chrome, Kiwi, Yandex и другие. в т.ч. на Android. 

📥 Установка Tampermonkey    
Если у вас ещё нет расширения Tampermonkey, установите его из магазина вашего браузера:    

Firefox: https://addons.mozilla.org/firefox/addon/tampermonkey/    

Chrome/Edge: https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo    

Другие браузеры: ищите «Tampermonkey» в их магазинах расширений или на оффициальном сайте.    

Следуйте инструкциям по установке. Дайте необходимые разрешения, в т.ч. к локальным файлам.    

📜 Добавление скрипта    
Скачайте актуальную версию скрипта файл FBCS-BB_For_Tampermonkey.user.js из этой ветки.    

Откройте Tampermonkey (значок в панели расширений браузера) и в панели управления выберите «Создать новый скрипт».    

Удалите весь шаблонный код и полностью вставьте содержимое актуального кода или добавьте скачаный файл (на ПК можно просто перетянуть файл в окно расширения)    

Скрипт автоматически активируется на fb-cs.ru.    

⚙️ Настройка    
Аналогично Safari-версиям, используется хэш #nastroyki:    

Перейдите на fb-cs.ru/place/#nastroyki (или просто fb-cs.ru/#nastroyki).    

В появившемся окне измените настройки и нажмите «Сохранить» или Отмена чтобы выйти без применения изменений.    

Настройки сохраняются в локальном хранилище браузера и действуют сразу.
