🍎 **Версия для Safari (iOS и MacOS)**    

Два варианта UserScript для приложения **Userscripts Safari** (бесплатно в App Store).    
Предназначены только для браузера Safari на устройствах Apple.

📥 **Установка** приложения:

Рекомендуется ознакомится с Оригинальной инструкцией по установке и использованию программы [https://github.com/quoid/userscripts?tab=readme-ov-file#readme]    

На iPhone / iPad / Mac откройте App Store и скачайте приложение Userscripts.    

Откройте приложение, выберите папку где будут располагаться скрипты.        

Добавте в эту папку файл скачанный из этой ветки FBCS-BB-for-Safari:    

FBCS-BB_For_iOS_Safari.user.js – урезанная версия для iOS и MacOS (не поддерживает работу с api и soket, работает только с данными Dom).

FBCS-BB_For_MacOS_Safari.user.js – почти полный аналог основной версии FBCS-BB-for-Chrome, работает только на Mac.


**Активация в Safari iOS / iPadOS**   

Настройки –> Приложения –> Safari –> Расширения –> Разрешите использование расширения и дайте запрашиваемые разрешения)    

В разделе «Разрешения» также убедитесь, что для сайта fb-cs.ru разрешена работа.


**macOS**

Откройте Safari → Настройки (Command + ,) → Расширения.        

Поставьте галочку рядом с «Userscripts».        

В появившейся панели управления Userscripts (иконка в панели инструментов) проверьте, что скрипт активен.        

Стоит так же включить режим разработчика.    


Настройка бейджей    

В обеих версиях (iOS и Mac) интерфейс настроек открывается через хэш #nastroyki.      

Как открыть настройки:      

Перейдите на любую страницу fb-cs.ru и добавьте в конец адресной строки #nastroyki.    

Например:    

https://fb-cs.ru/place/#nastroyki    

или просто https://fb-cs.ru/#nastroyki.    

Откроется модальное окно с настройками.    

Измените нужные параметры и нажмите «Сохранить».    

Чтобы закрыть окно без сохранения, нажмите «Отмена» или просто перейдите на другой URL без хэша.
